# External API type boundaries

These annotations describe the inspected pinned dependencies. They contain no
runtime implementation. Numerical qualification executes the installed GNN,
Realizing Emptiness and pymdp packages; the dependency provenance receipt binds
their distributions and source commits.

The SciPy overlay declares only the consumed scalar `stats.t.ppf` call (including
its real optional location/scale keywords). Its signature was checked against
`rv_continuous.ppf` documentation and a real scalar invocation; the result is
`numpy.float64`. Installed SciPy continues to supply the numerical implementation.

The defusedxml overlay declares only its consumed safe `fromstring` call and the
`DefusedXmlException` hierarchy. Both signatures were inspected in the installed
implementation. The runtime dependency parses SVG legend groups; malformed XML
and entity declarations are exercised as real rejection cases.
