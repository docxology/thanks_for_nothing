# Documentation map

Current settings, independent-unit counts, publication quantities and producer
selectors are [generated from the run](../output/reports/research_summary.md).
The [publication build receipt](../output/reports/publication_build.json) binds
the current manuscript and documentation products to their generating source
while preserving the numerical run's original receipt.
The maintained guides explain responsibilities and assumptions. Dated source
dossiers and revision plans preserve the scope of their original observations.

For a first reading, open the [rendered manuscript](../output/manuscript.html)
and follow the [question-by-question reading guide](manuscript-reading-guide.md).
It connects the main argument to precise supplemental methods, figures and
complete interval tables. For a computational review, begin with the model
contract, statistical units and reproducibility guide; for an interpretive
review, begin with the scholarship synthesis and evidence ceilings.

## Manuscript and executable companions

The [main manuscript](manuscript/manuscript.md) develops the argument;
the [technical supplement](manuscript/supplement.md) retains complete formal
methods, results, interval tables and prospective empirical design.
[DESIGN.md](../DESIGN.md) is the visual authority.

The companions cover [concepts and practice](../notebooks/gratitude_absence.ipynb),
[belief updating](../notebooks/belief_updating.ipynb),
[gaze and emptiness](../notebooks/gaze_emptiness.ipynb), and
[boundary inquiry](../notebooks/boundary_gaze.ipynb).
The introductory companion uses a small declared design; the others recompute
canonical analyses or replay complete canonical records.

The [source catalog](../data/scholarship/sources.json) distinguishes metadata,
abstract and full-text reading. No simulation, quotation or successful software
gate by itself establishes a human gratitude or realization effect.
