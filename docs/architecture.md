# Architecture

The package separates archived source behavior, corrected synthetic experiments,
new inquiry mechanisms, and their publication. Scripts are thin entry points;
scientific logic belongs in the package. [Generated current facts](../output/reports/research_summary.md)
provide actual versions, quantities and selectors.

## Authority and data flow

`standalone_gnn` expands the authoring declarations into complete categorical GNN
instances, preserves and re-admits those bytes, and binds actual consumers to
their numerical evidence. Known query and latent variables form the controlled
joint-state basis; conditional channels are recovered from the admitted arrays.
The generative catalog and native graph admission reject omitted coverage or
stale source/consumer bindings. See [the model contract](model-contract.md#complete-standalone-generative-laws).

## Actual dependency consumption

GNN and Realizing Emptiness are immutable VCS dependencies. Their distributions,
commits and executing-module digests appear in
[provenance](../output/data/provenance.json). The
[upstream currentness snapshot](../data/provenance/realizing-emptiness-currentness.json)
records its observation time separately from reproducible runtime admission.

The model registry consumes the real GNN Markdown parser, semantic validator and
canonical POMDP builder. Attention invokes the native GNN/pymdp executor and reads
its receipts, then separately evaluates a fixed-process counterpart with actual
pymdp inference/policy APIs. The native executor uses matched agent/world A;
that scope does not automatically transfer to the new finite policies.

Realizing Emptiness supplies actual KL, Blackwell risk, exact binomial,
QRF/support, free-energy, practice-map, ongoing-revision and Gaussian interfaces.
The [integration review](emptiness-integration-research.md) and
[boundary dossier](boundary-gaze-research.md) document exact consumed behavior.
Typing overlays describe those interfaces; they do not replace implementations.

## Persistence and replay

`run_pipeline` coordinates four boundaries: `generate_research` computes the
research records, `write_bundle_evidence` persists them with the selected analysis
protocol, `build_publication_products` renders the products, and `validate_project`
qualifies the complete chain. Numerical execution does not import the renderer or
write artifacts. Product construction does not regenerate the synthetic cohorts.
Exceptions propagate to the caller; a partial product directory is retained as
failure evidence and cannot be reported as a successful run. Notebook execution
uses the preserved selected analysis protocol, including its timeout budget.
The selected directory must supply every packaged model declaration. Admission
precedes copying, so a previous output directory cannot supply missing selected
inputs or have its preserved models partly overwritten by an incomplete selection.

The bundle reader reconstructs typed persisted records. Figure and manuscript
producers consume the same bundle. Previews may reuse saved records for design
iteration, but only a fixed-input complete run qualifies the current source,
numerics, figures, paper and executed companions together.

The variable ledger binds every used value, selector, producer and authoring
component. The figure map binds scientific input and PNG/SVG bytes. Generated
documentation facts replay from the same records; guide indexing and local links
have a separate bounded audit. The complete artifact inventory includes all
requested products.

[Reproducibility](reproducibility.md) covers runtime and installed-wheel
qualification. [The model contract](model-contract.md) describes inference
authority. [Evidence ceilings](evidence-ceilings.md) prevent a successful finite
calculation from becoming an empirical, clinical or realization claim.
