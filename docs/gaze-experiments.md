# Gaze reconstruction, learned transfer and active inquiry

These are separate computational experiments. They consume real pinned GNN and
Realizing Emptiness interfaces, but do not measure eye movements or infer scene
semantics from painting pixels. [Current facts](../output/reports/research_summary.md)
supply executed counts and budgets.

## Exact source target

The original adapter retains the initial neutral state and alternating agent
runs under a shared RNG. The [source dossier](yarbus-research.md) distinguishes
actual code, cached images and transcribed paper bars. Reconstructed occupancy
appears in [the typed gaze record](../output/data/gaze.json.gz); no manually edited
likelihood is relabeled as learned after-practice change.

The source's expected-value-minus-entropy expression is checked against an
independent preference-plus-ambiguity oracle. Its controlled transition tensor
uses the original action/next/previous convention, explicitly adapted to canonical
next/previous/action indexing. The convention alone is not a transition defect.

## Frozen learning and distinct bridges

`run_learning_experiment` returns the corrected study and retained learned channels;
`run_study` preserves its stable study-only interface. Each channel has a complete
paired identity, world, condition, exposure digest and normalized pre/post matrix.
Assessment observations do not train it.

The likelihood bridge embeds the actual learned channel into registered scene
locations. The alternative posterior-readout projection mixes fixed attention
templates using an assessed world readout. Perturbing that readout affects the
projection but not the direct learned-likelihood policy. Neither bridge is fitted
to unavailable source-after code. The common external process scores every
location, and pre/post paths share potential action uniforms.

## Active sampling and what is scored

The GNN gaze declaration owns region channels, registration, candidate sequences,
spatial costs, policy weights and budgets. Restricted/open priors come from actual
upstream structural admission. Candidate identity is fixed within an episode;
each context window resets its prior. This is not a persistent learned change-point
model across windows.

Inquiry adds exact expected information gain, checked against expected posterior
KL and known/identical-channel controls. Utility, information and movement enter
a declared weighted one-step policy; this is not a claim that pymdp executes a
full expected-free-energy planner for the new extension.

Time-by-region outcomes and action uniforms remain paired across conditions.
Only the selected observation updates belief. Prequential loss uses exact
population cross-entropy across the full registered scene before that update;
a policy is not scored only where it chose to look. Useful restricted support
and contradicted support therefore define different settings.

## Independent units, uncertainty and paths

Transfer inference resamples complete paired agent-world units within fixed
worlds. Active inference first averages repeated windows within each independent
replicate, then resamples complete vectors. Conditions, sampled sites and
observations do not become extra subjects.

Pointwise percentile, studentized bootstrap and analytic intervals remain in the
complete tables. [Joint uncertainty](joint-uncertainty.md) preserves the full
exploratory family, exact identities, unavailable constants and known-answer
coverage failures. Main figures separately show learned attention transfer and
inquiry versus already-open utility/uniform comparators.

Path descriptors include coverage, revisits, Euclidean step length, ordered
transition entropy and occupancy relative to the actual uniform-site region
masses. Their baseline derives from the registered locations, not equal valence
thirds. Paths are unsmoothed; source/transfer paths count the initial location,
whereas active episodes contain sampled destinations. No descriptor has measured
fixation-duration, visual-angle or saccade-speed units.
